# abv-forwarder

Два малки бота, които работят безплатно в GitHub Actions:

1. **Препращане** (`forward.py`, на всеки ~10 минути): новите писма от пощата в abv.bg
   се препращат към друг адрес.
2. **Дневен преглед** (`digest.py`, всяка сутрин ~7:00): едно писмо със списък на писмата
   от последните 24 часа (подател, тема, първите редове, прикачени файлове).
   Запитванията от формата в Netlify са най-отгоре.

В repo-то няма имейли, пароли или други лични данни. Всички настройки са:
- **локално** в `.env` (в `.gitignore`, не се качва);
- **в GitHub** в Settings → Secrets (криптирани, не се виждат в логовете).

## Препращане

- abv.bg няма IMAP, затова ботът чете по **POP3** (`pop3.abv.bg`) и праща през `smtp.abv.bg`.
- Чете само „Кутия“. Спамът не се препраща. Писмата в abv не се трият.
- Препратеното писмо има същата тема, текст и прикачени файлове.
  Подателят се вижда като „Име (през abv)“, а „Отговор“ отива директно при него.
- При първото пускане само запомня кои писма вече има (`state.json`, като кратки хешове). Старите писма **не** се препращат.
- Писма от самия `ABV_USER` или от `FORWARD_TO` не се препращат, за да не стане кръг.
- Логовете не съдържат имейл адреси (repo-то е публично и логовете също).

## Настройка (веднъж)

1. Качи repo-то в GitHub. Файловете `forward.yml` и `digest.yml` трябва да са в `.github/workflows/`.
2. Repo → **Settings → Secrets and variables → Actions → New repository secret**:

   | Име | Какво |
   |---|---|
   | `ABV_USER` | адресът в abv.bg |
   | `ABV_PASSWORD` | паролата за abv.bg |
   | `FORWARD_TO` | адресът, към който се препраща |

3. Repo → **Actions** → „Препращане abv → office“ → **Run workflow**.
   Първото пускане само записва начална точка.
4. Прати тестово писмо до abv адреса и пусни пак **Run workflow** (или изчакай 10–20 минути).

### Локално пускане

```
copy .env.example .env      # попълни стойностите в .env
python forward.py
python digest.py
```

## Дневен преглед

Работи само с abv без допълнителни настройки. Прегледът отива на `FORWARD_TO`.
За друг адрес добави secret `DIGEST_TO`.

За да включва и писмата от Gmail / Google Workspace пощата:

1. В Google акаунта на тази поща → **Security** → включи **2-Step Verification**.
2. Пак там → **App passwords** → създай парола с име `digest` и копирай 16-те букви.
3. Добави secrets `GMAIL_USER` (адресът) и `GMAIL_APP_PASSWORD` (16-те букви, без интервали).
4. Actions → „Дневен преглед на пощата“ → **Run workflow**, за да провериш веднага.

Писмата, които ботът вече е препратил, не се броят втори път.

## Добре е да знаеш

- GitHub пуска графика със закъснение, понякога 10–20 минути.
- Ако abv откаже входа, в лога на Actions има грешка при `login`. Влез в abv от браузъра и пробвай пак.
- Ако смениш паролата на abv, смени и `ABV_PASSWORD` в Secrets (и в `.env`).
- GitHub спира графиците в repo без промени за 60 дни. Ботът обновява `state.json`
  при всяко ново писмо, така че докато идват писма, това не се случва.
- Спиране: Actions → workflow-а → `...` → **Disable workflow**.
